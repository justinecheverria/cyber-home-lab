# cyber-home-lab

## OVERVIEW
This is a project that documents the development of a virtual cyber home lab that simulates a small enterprise network. The lab provides a controlled environment for practicing system administration, networking, Active Directory, security hardening, monitoring, and incident response.

The environment includes a Windows Server, Windows 11, Linux, and security-focused systems running as virtual machines.

## OBJECTIVES
- Build and configure a virtual enterprise network
- Deploy Windows Server and Active Directory Domain Services
- Create and manage domain users, groups, and organizational units
- Join Windows workstations to an Active Directory domain
- Configure DNS and network services
- Apply security policies and system-hardening techniques
- Introduce Linux systems into the environment
- Generate and analyze security events
- Practice basic incident detection and response

## LAB ENVIRONMENT
| Component | Purpose |
|---|---|
| Windows Server 2025 | Domain Controller, Active Directory, and DNS |
| Windows 11 | Domain-joined employee workstation |
| Ubuntu Linux | Linux server and administration practice |
| Kali Linux | Security testing workstation |
| VirtualBox | Virtualization platform |

# HARDWARE 
Host system used for the lab:
- Intel Core i5-10400
- 16 GB RAM
- SSD storage
- Hardware virtualization enabled
